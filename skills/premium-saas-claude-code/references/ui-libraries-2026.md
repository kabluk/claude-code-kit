# Recommended UI Libraries 2026 (Premium SaaS)

## Core Product UI (use these)
- **shadcn/ui** — primary foundation for product interfaces
- **Radix UI** — accessible unstyled primitives
- **Tailwind CSS** — utility styling
- **Tremor** — dashboards and charts
- **HeroUI** or **Origin UI** — additional polished app components

## Marketing / Landing only
- Aceternity UI
- Magic UI
- Motion Primitives

## Rules
1. Choose one foundation (almost always shadcn + Tailwind + Radix).
2. Add at most two complementary libraries.
3. Never mix many different visual languages.
4. Prefer libraries that expose design tokens and composition over opinionated full themes.
5. For data-heavy tables, invest extra design time — tables are the primary surface of most B2B SaaS.

## Anti-pattern
Using five different component libraries on the core product UI. The result looks like fourteen designers who never spoke to each other.
